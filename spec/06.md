# 06 — Stage 1: Readers

Readers do one thing: turn a `Source` ([03](03.md)) into a `PageDoc`. They are
"purely technical" — no classification, no normalization (that's [08](08.md)+).
This chapter covers fetching and the reader contract; asset handling is in
[07](07.md).

## Fetch modes

`Settings.fetch_mode` (CLI `--fetch-mode`) picks how a URL becomes a `PageDoc`:

- **`live` (default)** — the `LiveReader` navigates the URL in the chosen browser
  engine, captures the rendered DOM, and injects a `<base href>` pointing at the
  page's post-redirect origin. **Nothing is localized**: fonts, CSS and images
  stay online and are loaded by the browser at probe/preprocess/export time via
  the `<base>` over the network. This is the in-browser path issue 103 asks for —
  assets render exactly as the live site serves them. Local-file sources have
  nothing to fetch online, so `live` delegates them to the static reader.
- **`localize`** — fetch + download every asset to disk for a reproducible,
  fully offline archive (the original design; see [07](07.md)). Pick this when the
  output must survive the source going offline or changing.
- **`offline`** — shell out to a single-file archiver (`single-file` or
  `monolith`, per `offline_tool`) to inline everything into one self-contained
  `index.html` (the Tier-3 path in [07](07.md)). Degrades to `localize` when the
  tool is absent.

## Fetching Paths

- **Static (`httpx`)** — for pages that are complete in their server HTML
  (MkDocs, Hugo, exported static sites). Fast, no browser. `httpx[http2]`,
  `follow_redirects=True`, a sane timeout.
- **Dynamic** — for pages that assemble their DOM in JavaScript or require authentication
  or bypass bot-protection. We support a choice of three dynamic browser options:
  1. **Standard Playwright (`playwright`)** — Launch standard headless Chromium,
     `goto(url, wait_until="networkidle")`, and extract `page.content()`.
  2. **PlaywrightAuthor (`playwrightauthor`)** — Use the locally cloned package
     `./private/playwrightauthor/` (from `playwrightauthor` on PyPI). This driver
     launches Chrome for Testing with persistent browser profiles, maintaining logged-in
     user sessions across runs.
  3. **CloakBrowser (`cloakbrowser`)** — Use the `cloakbrowser` custom Chromium package
     designed to bypass anti-bot detection walls (e.g. Cloudflare, DataDome) by compiling
     stealth patches directly into the browser binary.

Default heuristic: try static; if the body is suspiciously empty or a known
client-rendered fingerprint appears ([08](08.md)), escalate to dynamic (defaulting
to standard playwright or using the user-specified dynamic browser option). The user
can force any path or driver with a strategy hint.

```python
import httpx
from playwright.sync_api import sync_playwright

def read_static(url: str) -> str:
    return httpx.get(url, follow_redirects=True, timeout=30).text

def read_dynamic_playwright(url: str, w: int, h: int) -> str:
    with sync_playwright() as p:
        b = p.chromium.launch()
        page = b.new_context(viewport={"width": w, "height": h}).new_page()
        page.goto(url, wait_until="networkidle")
        html = page.content()
        b.close()
        return html

def read_dynamic_playwrightauthor(url: str, profile: str = "default") -> str:
    from playwrightauthor import Browser
    with Browser(profile=profile) as browser:
        page = browser.get_page()
        page.goto(url)
        return page.content()

def read_dynamic_cloakbrowser(url: str) -> str:
    from cloakbrowser import CloakBrowser
    with CloakBrowser() as browser:
        page = browser.new_page()
        page.goto(url)
        return page.content()
```

## Local files

`SourceKind.FILE` skips fetching: copy the file (and a sibling asset directory,
if present) into the working tree, then run localization to normalize paths. A
`file://` URL is treated as a file.

## The reader plugin contract

Readers are entry points under `vexy_dexypy.readers` ([02](02.md)). The ABC:

```python
class Reader(Protocol):
    name: str
    def can_read(self, source: Source) -> float: ...     # 0..1 confidence
    def read(self, source: Source, settings: Settings) -> PageDoc: ...
```

Ships with `static` and dynamic (`playwright`, `playwrightauthor`, `cloakbrowser`) readers.
A future `monolith` reader ([07](07.md)) or an authenticated reader can be added without
core changes.

## Politeness & robustness

- Honour a configurable timeout and a single retry with backoff+jitter
  ([22](22.md)) — no elaborate retry framework (anti-bloat, [01](01.md)).
- Set a real `User-Agent`; respect `--no-robots` only when the user opts in
  (the user owns most target pages).
- A fetch failure raises a typed `ReadError` with the URL and HTTP status; the
  CLI turns it into a clear message and exit `1` (nothing to render).

## Output

The reader writes `PageDoc.html_path` (`index.html` with rewritten asset refs),
populates `asset_dir`, and computes a provisional `content_hash` after
localization ([07](07.md), [21](21.md)). Title and any `meta[generator]` are
captured into `PageDoc.meta` for the classifier.
