# 18 — Stage 5: CSS Paged-Media Exporters

Two engines render via CSS Paged Media rather than browser screenshotting.
They produce smaller, typographically cleaner PDFs and obey `@page`/`break-*`
precisely — ideal for documentation-shaped pages.

## Vivliostyle CLI (primary paged engine)

- Node, Chromium-backed typesetting engine; the best CSS Paged Media coverage of
  the open engines (running headers, margin boxes, page counters).
- **AGPL-3.0 — shell out via subprocess, never link against `@vivliostyle/core`**
  ([16](16.md), [24](24.md)).

```python
class VivliostyleExporter:
    name = "vivliostyle"; needs_js = True; supports_paged_media = True
    def available(self):
        return shutil.which("vivliostyle") is not None
    def export(self, job, out):
        run(["vivliostyle", "build", str(job.html_path),
             "-s", f"{job.plan.stage_w}px,{job.plan.stage_h}px",
             "-o", str(out)], timeout=120, check=True)
        return out
```

Install: `npm install -g @vivliostyle/cli`. Skipped with a notice when `node`
isn't present ([05](05.md)).

## Prince (opt-in premium)

- The reference CSS Paged Media implementation; supports JS, SVG foreignObject,
  advanced OpenType. Proprietary: free for non-commercial use, paid otherwise.
- **Off by default.** Enabled only when `engines.prince_path` is set
  ([05](05.md)); `available()` returns the path's existence.

```python
class PrinceExporter:
    name = "prince"; needs_js = True; supports_paged_media = True
    def available(self): return bool(settings.engines.prince_path)
    def export(self, job, out):
        run([settings.engines.prince_path, str(job.html_path),
             "-o", str(out), f"--page-size={job.plan.stage_w}px {job.plan.stage_h}px"],
            timeout=120, check=True)
        return out
```

## Why not Paged.js?

`pagedjs-cli` has too slow a release cadence to depend on (Snyk-flagged
inactive; reports split). Vivliostyle covers the same need with healthier
maintenance. Do not ship a Paged.js exporter ([`../RESEARCH.md`](../RESEARCH.md)).

## Choosing among them

The classifier recommends Vivliostyle first for docs and Webflow's
Playwright path otherwise ([08](08.md)). Users run any subset via
`--strategies`. The engines disagree usefully — that disagreement is the deck
menu the user picks from ([01](01.md)).
