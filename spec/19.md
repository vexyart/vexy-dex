# 19 — Stage 5: Slide-Framework Exporter (Reveal.js + DeckTape)

When the input has been normalized into a reveal.js deck ([11](11.md),
[15](15.md)), the cleanest path to per-slide PDFs is DeckTape, which knows
reveal.js natively and captures each slide as its own frame — no scaling
artefacts, no pagination guesswork.

## DeckTape

- MIT, v3.16.x (2026), built on Puppeteer (bundles its own Chrome).
- Knows reveal.js, Slidev, impress.js, Bespoke, remark, Shower, WebSlides, plus
  a `generic` key-emulation fallback.
- One PDF page per reveal slide; `--fragments` emits a page per fragment.

```python
class DeckTapeExporter:
    name = "decktape"; needs_js = True; supports_paged_media = False
    def available(self):
        return shutil.which("decktape") is not None or shutil.which("npx")
    def export(self, job, out):
        run(["npx", "decktape", "reveal",
             "--size", f"{job.plan.stage_w}x{job.plan.stage_h}",
             str(job.html_path), str(out)], timeout=180, check=True)
        return out
```

Install: `npm install -g decktape`.

## Serving the deck

DeckTape can take a file path or a URL. Reveal.js generally behaves with
`file://`, but some asset/relative-path setups need an HTTP origin. The exporter
may spin a throwaway local static server (stdlib `http.server` on an ephemeral
port) rooted at the `RenderJob` directory, point DeckTape at
`http://127.0.0.1:<port>/index.html`, and tear it down after. This stays offline
— the server only serves the localized files ([07](07.md)).

## Why this is the cleanest reveal path

Reveal.js's own `?print-pdf` + browser print works but is fiddly to drive
headlessly and prone to scaling drift. DeckTape was built for exactly this and
captures each slide deterministically. For Webflow input — already reveal-shaped
via `webflow2reveal` ([12](12.md)) — DeckTape is often the best-looking strategy.

## Chromium version drift

DeckTape bundles its own Puppeteer Chrome. If that lags and breaks on a page,
point it at Playwright's downloaded Chromium with `--chrome-path` to skip a
second browser install and stay on a known-good version
([`../RESEARCH.md`](../RESEARCH.md)).

## Relationship to other strategies

DeckTape consumes the same normalized reveal HTML the paged engines do, but
treats slides as frames rather than pages. It complements rather than competes:
a run might emit `playwright/`, `weasyprint/`, and `decktape/` folders, and the
hero slides often look best from `decktape/` while text slides read best from
`weasyprint/` — precisely the cherry-picking the tool exists to enable
([01](01.md)).
