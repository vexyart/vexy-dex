# 16 — Stage 5: Exporter Framework & Plugin API

Exporters turn a `RenderJob` ([15](15.md)) into a multi-page PDF. There are
several; each is a plugin. Running them in parallel and emitting divergent decks
is the product ([01](01.md), [02](02.md)).

## The contract

```python
class Exporter(Protocol):
    name: str                        # strategy name / output folder
    needs_js: bool                   # True → Chromium-class engine
    supports_paged_media: bool       # True → honours @page / break-*
    def available(self) -> bool:     # are runtime deps present? (binary, node)
        ...
    def export(self, job: RenderJob, out: Path) -> Path:   # → multi-page PDF
        ...
```

`available()` lets the orchestrator skip a strategy whose dependency is missing
(no `node`, no Prince licence) with a notice rather than a crash ([05](05.md)).

## Discovery

```toml
[project.entry-points."vexy_dex.exporters"]
playwright  = "vexy_dex.exporters.playwright:PlaywrightExporter"
weasyprint  = "vexy_dex.exporters.weasyprint:WeasyPrintExporter"
vivliostyle = "vexy_dex.exporters.vivliostyle:VivliostyleExporter"
decktape    = "vexy_dex.exporters.decktape:DeckTapeExporter"
prince      = "vexy_dex.exporters.prince:PrinceExporter"
```

## Capability-aware dispatch

The orchestrator uses the capability flags + the classifier's recommendation
([08](08.md)) to order strategies, but `--strategies` ([04](04.md)) is
authoritative. `needs_js` engines that require a browser pool are scheduled
through the Chromium `CapacityLimiter` ([21](21.md)); pure-Python WeasyPrint runs
without that constraint.

## Parallel execution

Each strategy is independent, so exporters run concurrently (`anyio` task group,
[21](21.md)). One exporter raising does not cancel the others — it yields a
failed `DeckResult` ([03](03.md), [22](22.md)). The orchestrator gathers all
outcomes into a run summary.

## Subprocess discipline

Node/CLI engines (Vivliostyle, DeckTape, Prince) run via `subprocess` with:

- an explicit timeout (a hung Chromium must not wedge the run);
- captured stdout/stderr surfaced in the failure message;
- the localized `RenderJob.html_path` passed as a file path (offline,
  [07](07.md)).

Avoid linking against AGPL engine internals — shell out only ([18](18.md),
[24](24.md)).

## Adding an exporter

Implement the ABC, register an entry point, declare deps. No core edit. This is
how the tool grows a fifth engine if two of the four fail twice (pplx's rule).
