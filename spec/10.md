# 10 — Stage 2: Optional Vision/LLM Analysis

A local vision model can refine pagination on pages the heuristic ([09](09.md))
struggles with — unstructured div-soup, image-heavy designs, slides where the
visual rhythm doesn't match the DOM. This is **strictly opt-in** (`--vision`,
[04](04.md)), cached, and never on the critical path. The deterministic plan
always exists; vision only adjusts it.

## Model

- **MiniCPM-V 4.6** GGUF — Apache-2.0, ~1.3 B params, ~2 GB, strong OCR, runs on
  consumer hardware (CPU or modest GPU). Released May 2026.
  `huggingface.co/openbmb/MiniCPM-V-4.6-gguf`.
- Serve one of two ways:
  - **Ollama** — `ollama pull openbmb/minicpm-v4.6`, OpenAI-compatible HTTP at
    `localhost:11434`. Easiest to embed.
  - **llama.cpp** — `llama-mtmd-cli` / `llama-cpp-python[server]`, build ≥ b9049.

## The footgun

llama.cpp enables a "thinking" template by default (after PR #20606) that
**breaks MiniCPM-V Instruct output**. Always pass `--reasoning off` (CLI) or the
equivalent serving flag. Document this prominently — it is the single most
likely cause of garbage output (noted in [`../RESEARCH.md`](../RESEARCH.md)).

## Workflow

1. Playwright screenshots the rendered page (full-height, or per provisional
   slide region from [09](09.md)).
2. Send each screenshot to the model with a tight prompt:
   *"List the y-coordinates where a new slide should start. Output JSON only:
   `{breaks: [{y, reason}]}`."*
3. Parse with `instructor`/Pydantic — never accept free prose. Reject and fall
   back to the heuristic plan on malformed output.
4. Merge: vision breaks adjust nearby heuristic breaks within a tolerance; novel
   high-confidence vision breaks are added; the heuristic plan is the floor.

```python
@dataclass
class VisionBreak(BaseModel):   # validated, not trusted
    y: float
    reason: str
```

## Caching

Vision is slow and deterministic for a fixed input. Cache by
`hash(screenshot_bytes) + model_id` under `out/<slug>/_meta/vision/`
([21](21.md)). A second run with `--vision` reuses the cached plan.

## Other uses (future, behind the same flag)

- Generate alt text for SVG embeds in the reveal preview ([20](20.md)).
- Verify detected slide titles match `h1/h2` text.

## When to escalate

If MiniCPM-V hallucinates titles/breaks more than ~5% on the test corpus, swap
to **Qwen2.5-VL-7B** (Apache-2.0, heavier, better at small text/charts) via the
same Ollama interface — a config change ([05](05.md)), not a code change.

## Boundary discipline

This chapter is the only place an external model touches the pipeline. It obeys
the same plugin/contract rules: input is `PageDoc + SlidePlan`, output is an
adjusted `SlidePlan`. If the model server is down, log a warning and proceed
with the heuristic plan — vision is an enhancement, not a dependency
([01](01.md), [22](22.md)).
