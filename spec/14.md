# 14 — Stage 3: Generic & Other Importers

Most pages are not Webflow or MkDocs. The generic importer is the workhorse;
Bubble, Docusaurus, and Framer get light rule sets that mostly delegate to it.

## Generic importer

The default for static-generator output (Hugo, Jekyll, Astro, Next, Gatsby) and
anything unrecognized. Trust the semantic HTML.

1. **Extract main content.** Run `trafilatura.extract(html,
   output_format="html", include_images=True, include_links=True)` to strip
   nav/footer/aside and recover the article body with structure intact.
   Trafilatura had the best F1 in the cited 2023 SIGIR benchmark.
2. **Clean.** Optionally pass through `clear-html` to flatten residual div-soup
   for the paged engines.
3. **Split by `<h2>`.** Apply `split_by_heading` ([11](11.md)) using the
   `SlidePlan` breaks ([09](09.md)) where the heading structure is thin.
4. **Wrap** into the canonical reveal structure.

```python
import trafilatura

class GenericImporter:
    name = "generic"
    def detect(self, page): return 0.1   # always a low-confidence fallback
    def transform(self, page, plan):
        main = trafilatura.extract(page.html_path.read_text(),
                                   output_format="html",
                                   include_images=True, include_links=True)
        sections = split_by_heading(parse(main), levels=("h1", "h2"),
                                    max_h=plan.stage_h)
        return write_normalized(page, wrap_reveal(sections))
```

`detect` returns a deliberately low score so any specific importer wins; the
orchestrator falls back to generic only when nothing else matches.

## Bubble

- **Detect:** `bubble-element`, `[data-bb-id]`.
- **Transform:** Bubble emits deeply nested container divs with absolute
  positioning. Flatten by depth and rewrite `position: absolute` → `relative`
  on the main wrapper so content flows; then hand off to the generic split. This
  is ad-hoc and best-effort — Bubble pages vary widely.

## Docusaurus

- **Detect:** `#__docusaurus`, `.theme-doc-markdown`.
- **Transform:** keep `.theme-doc-markdown`, drop the navbar/sidebar/footer,
  split by `<h2>`. Effectively MkDocs-like; can share most of [13](13.md)'s
  helpers.

## Framer

- **Detect:** `data-framer-name`.
- **Transform:** Framer is JS-heavy and best fetched via the dynamic reader
  ([06](06.md)) or `monolith` freeze ([07](07.md)). After freezing, treat
  top-level framer sections like Webflow sections; otherwise fall to generic.

## Extending

Each builder above is a thin plugin reusing `vexy_dex.dom` helpers. Adding
Squarespace/Wix/WordPress is the same shape: one fingerprint ([08](08.md)) + one
`transform` that mostly delegates to generic with a chrome-selector list. Resist
over-fitting — generic + trafilatura already handles the long tail.
