# 14 — Stage 3: Generic & Other Importers

Most pages are not Webflow or MkDocs. The generic importer is the workhorse;
Bubble, Docusaurus, and Framer get specific DOM preprocessing rules. In `vexy-dexypy`,
all these importer transforms are implemented within the JS package `vexy-dexyjs`
running in the browser context.

## Generic importer

The default for static-generator output (Hugo, Jekyll, Astro, Next, Gatsby) and
anything unrecognized. Trust the semantic HTML.

1. **Extract main content.** Python's `trafilatura` is used as a backend to extract clean
   HTML content (stripping nav/footer/aside). This clean content is loaded into the
   browser context.
2. **Clean & Parse.** `vexy-dexyjs` parses the DOM in the browser, flattens residual div-soup,
   and standardizes layouts.
3. **Split by `<h2>`.** It splits the content by headings and apply the breaks from `SlidePlan`.
4. **Wrap** into the canonical slide layout.

```python
class GenericImporter:
    name = "generic"
    def detect(self, page): return 0.1   # always a low-confidence fallback
    def transform(self, page, plan):
        # Extract content using Python trafilatura
        import trafilatura
        raw_extract = trafilatura.extract(page.html_path.read_text(),
                                          output_format="html",
                                          include_images=True, include_links=True)
        # Load raw_extract into browser and normalize via vexy-dexyjs
        html = run_js_preprocessor_on_content(raw_extract, "generic", plan)
        return write_normalized(page, html)
```

## Bubble

- **Detect:** `bubble-element`, `[data-bb-id]`.
- **Transform:** Bubble emits deeply nested container divs with absolute positioning.
  `vexy-dexyjs` traverses the DOM in the browser, flattens by depth, rewrites absolute
  positioning to relative on the main wrappers so content flows, and applies the generic
  split.

## Docusaurus

- **Detect:** `#__docusaurus`, `.theme-doc-markdown`.
- **Transform:** `vexy-dexyjs` isolates `.theme-doc-markdown` inside the browser, drops the
  navbar/sidebar/footer, and splits by `<h2>` / breaks.

## Framer

- **Detect:** `data-framer-name`.
- **Transform:** Framer is JS-heavy and best fetched via the dynamic reader ([06](06.md))
  or `single-file-cli`/`monolith` freeze ([07](07.md)). In the browser, `vexy-dexyjs`
  identifies and processes top-level Framer sections like Webflow sections, falling back to
  generic extraction.

## Extending

Adding Squarespace/Wix/WordPress follows the same pattern: one fingerprint rule in the
Python classifier ([08](08.md)) and one JS preprocessor rule set in `vexy-dexyjs`.
Resist over-fitting — the generic extraction path covers the vast majority of web layouts.
