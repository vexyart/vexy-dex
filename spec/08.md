# 08 — Stage 2: Framework Classification

Before normalizing, vexy-dex decides *what kind of page* it has. The framework
label routes the page to the right importer ([11](11.md)–[14](14.md)) and
suggests a strategy order ([05](05.md)).

## A rules engine, not a library

All three current research reports (cla, dsk, pplx) reach the same conclusion:
**do not depend on Wappalyzer.** `python-Wappalyzer` last shipped 0.3.1 in 2020;
Wappalyzer itself went closed. Instead, a ~200-line rules engine matches short,
stable fingerprints. This is core, vexy-dex-specific glue — appropriate to write
ourselves.

## Fingerprints

```python
def classify(html: str, meta: dict) -> str:
    s = html.lower()
    gen = (meta.get("generator") or "").lower()
    if "data-wf-page" in s or "w-mod-js" in s or "data-w-id" in s:
        return "webflow"
    if "mkdocs-material" in gen or "md-content" in s or "data-md-component" in s:
        return "mkdocs-material"
    if "__docusaurus" in s or "theme-doc-markdown" in s:
        return "docusaurus"
    if "data-framer-name" in s or "framer.app" in s:
        return "framer"
    if "data-bb-id" in s or "bubble-element" in s:
        return "bubble"
    return "generic"
```

Per-framework signal detail:

- **Webflow** — `data-wf-page`, `[data-w-id]`, `html.w-mod-js`, classes
  `w-section/w-container/w-nav/w-layout-grid`, `webflow.js`.
- **MkDocs Material** — `meta[generator]="mkdocs-material 9.x"`, `md-content`,
  `md-typeset`, `md-nav`, `data-md-component`.
- **Docusaurus** — `#__docusaurus`, `.theme-doc-markdown`.
- **Framer** — `data-framer-name`, `framer.app` styles.
- **Bubble** — `bubble-element`, `[data-bb-id]`.
- **Static generators (Hugo/Jekyll/Astro/Next/Gatsby)** — trust
  `meta[generator]`; `__NEXT_DATA__`, `astro-*`, `gatsby-*` leak the framework.
  All route to `generic` ([14](14.md)) since their HTML is already semantic.

## Confidence, not certainty

`classify` returns a label plus a confidence; importers also expose
`detect(html) -> float` ([11](11.md)). When two frameworks both score, the
higher wins; ties fall back to `generic`. The label and score land in
`PageDoc.framework` and `PageDoc.meta` and are logged ([22](22.md)).

## Parsing tier

Classification only reads a few markers, so it runs on whatever parse is already
available. For the heavier importer work, prefer `selectolax` (Lexbor, ~25×
faster than BS4) on hot paths and `BeautifulSoup4 + lxml` where the code is
edited by hand (the `webflow2reveal` choice). See [11](11.md).

## Extensibility

A new framework is a new fingerprint plus a new importer plugin — no change to
the dispatcher. The fingerprint table lives in one module so adding a builder is
a one-function edit.
