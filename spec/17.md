# 17 — Stage 5: Chromium / Playwright Exporter

The workhorse exporter. Chromium renders exactly what a browser shows, executes
JavaScript, and honours every CSS feature — the right default for Webflow and
other styled/dynamic pages.

## Capabilities

- `needs_js = True`, `supports_paged_media = "partial"`.
- Chromium-only: `page.pdf()` raises on Firefox/WebKit. Pin the channel at
  launch (a documented constraint, [`../RESEARCH.md`](../RESEARCH.md)).

## Export

```python
from playwright.sync_api import sync_playwright

class PlaywrightExporter:
    name = "playwright"
    needs_js = True
    supports_paged_media = False
    def available(self): return True   # bundled dependency
    def export(self, job, out):
        w, h = job.plan.stage_w, job.plan.stage_h
        with sync_playwright() as p:
            page = p.chromium.launch().new_page(
                viewport={"width": w, "height": h})
            page.goto(job.html_path.as_uri(), wait_until="networkidle")
            page.add_style_tag(path=str(job.extra_css[0]))  # paged CSS (15)
            page.emulate_media(media="screen")
            page.pdf(path=str(out), width=f"{w}px", height=f"{h}px",
                     print_background=True, prefer_css_page_size=True)
        return out
```

## Locking the stage

- `prefer_css_page_size=True` makes Chromium respect the injected
  `@page { size }` ([15](15.md)) instead of a default letter size.
- Add `html, body { width:…; height:… }` via `add_style_tag` to defeat browser
  scaling, so one DOM section == one PDF page at the exact stage geometry.
- `print_background=True` keeps Webflow background colours/images.

## Media emulation

Webflow and marketing pages often hide content under `@media print`. Force
`emulate_media("screen")` so the rendered deck matches what the analyzer
([09](09.md)) measured — the analysis and the render must agree on visibility.

## Reuse the browser

Launching Chromium costs ~1–3 s. The orchestrator keeps a warm browser pool
([21](21.md)); the exporter accepts an injected `page`/context rather than
launching its own when pooled. The example above shows the standalone form for
the `render` CLI verb ([04](04.md)).

## Strengths and limits

- **Strength:** pixel parity with the live page; JS, web fonts, fl/grid, SVG —
  all work.
- **Limit:** no true CSS Paged Media (no running headers, no `@page :left`, weak
  orphan/widow control). For those, Vivliostyle ([18](18.md)) is
  the better strategy — which is exactly why vexy-dex runs all of them.
