# 24 — Packaging, Dependencies & Roadmap

## Project shape

```
vexy-dexypy/
  pyproject.toml
  src/vexy_dexypy/
    __main__.py            # fire.Fire(VexyDex)  (04)
    cli.py                 # the VexyDex class
    settings.py            # config + profiles    (05)
    model.py               # the IR dataclasses   (03)
    orchestrator.py        # fan-out, concurrency  (21)
    dom.py                 # shared DOM helpers    (11)
    readers/               # static, dynamic (playwright, author, cloak) (06,07)
    classify.py            # fingerprint engine    (08)
    paginate.py            # viewport break planner (09)
    vision.py              # optional MiniCPM-V     (10)
    importers/             # webflow, mkdocs, generic, … (12–14) [triggers vexy-dexyjs]
    preexport.py           # paged CSS / reveal     (15)
    exporters/             # playwright, vivliostyle, reveal, prince (16–19)
    writers.py             # split, svg, preview    (20)
    assets/                # bundled reveal.js, theme.css
  tests/  examples/  spec/
  vexy-dexyjs/             # companion NPM package for in-browser DOM transform
```

Use `hatch-vcs` for git-tag versioning.

## External (non-pip) tools

- **Node** (for Vivliostyle CLI, bundlers, and `vexy-dexyjs` script build): `npm i -g @vivliostyle/cli`.
- **monolith** (Rust): `cargo install monolith` / `brew install monolith` — for
  the freeze tier ([07](07.md)).
- **poppler** (`pdftocairo`): pulled in by `vexy-pdfsvgpy` for SVG ([20](20.md)).
- **Prince**: optional, user-installed, path in config ([18](18.md)).
- **Ollama / llama.cpp**: optional, for vision ([10](10.md)).

Missing externals degrade gracefully — the strategy is skipped with a notice
([05](05.md), [22](22.md)).

## Licence hazards (record all in DEPENDENCIES.md)

- **Vivliostyle CLI** — AGPL-3.0: shell out only, never link ([18](18.md)).
- **PyMuPDF** — AGPL/commercial: avoid; use pypdf/pikepdf ([20](20.md)).
- **Surya** — GPL-3.0, commercial for self-host: research-only ([10](10.md)).
- **Prince** — proprietary, opt-in.
- **webflow2reveal** — *not a dependency.* Its js compiler is adapted into the
  companion JavaScript library `vexy-dexyjs` ([12](12.md)). Once parity is reached
  in `vexy-dexyjs`, the old package is retired.
- **monolith** — CC0; **pypdf** — BSD; **pikepdf** — MPL-2.0;
  **Playwright/trafilatura/fire/MiniCPM-V** — Apache-2.0.

## Roadmap (from RESEARCH.md staging)

1. **MVP / walking skeleton** — dynamic+static reader, generic importer (`vexy-dexyjs`
   in-browser generic transform), Playwright exporter, pypdf writer, `build`/`split` CLI.
   One deck/sec on static pages.
2. **CMS-aware & JS preprocessor** — Build the companion JS package `vexy-dexyjs`, porting
   and generalizing Webflow and MkDocs importer logic to run inside the browser.
   Deploy `vexy-dexyjs` on NPM and CDNs, and verify Chrome extension compatibility.
   Once the JS preprocessor matches the legacy outputs, **retire the `webflow2reveal` package**.
3. **Optional intelligence & Offlinization** — Integrate advanced offlinization tools
   (SingleFile, monolith, juice, css-inline) into `vexy-dexyjs`. Support Ollama/llama.cpp
   vision-based break refinement.
4. **Later (out of v1 scope)** — Bubble/Framer/Squarespace JS preprocessor rules, a
   multi-page/crawler mode, alt-text generation.
