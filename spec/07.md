# 07 — Asset Localization & Offline Bundling

The offline guarantee ([01](01.md)): after Stage 1, every reference in
`PageDoc.html_path` resolves to a local file. No downstream engine ever touches
the network. This chapter is how that holds.

## What must be localized

- `<link rel=stylesheet>`, `<script src>`, `<img src>` and `srcset`, `<source>`.
- CSS-referenced assets: `@import` chains, `url(...)` backgrounds, `@font-face`
  web fonts.
- Protocol-relative (`//cdn…`) and absolute URLs rewritten to relative local
  paths.

## Three localization tiers

1. **Custom downloader (baseline, no extra dep).** A `ThreadPoolExecutor`
   walks the parsed DOM, downloads each asset into `asset_dir`, and rewrites the
   reference. This is gemi's `PageReader` pattern; it covers tag-referenced
   assets. Failures warn and continue — a missing analytics script must not stop
   a render.

2. **`pywebcopy` (static pages).** When the page is plain-static, `pywebcopy`
   mirrors the page and rewrites paths in one call, including CSS-referenced
   assets the naive walker misses.

3. **`monolith` freeze (hardest pages).** For JS-heavy pages, render the DOM in
   Chromium, then pipe through `monolith` (Rust, CC0) to inline every asset as a
   data URI into a single self-contained HTML file:

   ```bash
   chromium --headless --dump-dom URL | monolith - -I -b URL -o frozen.html
   ```

   A single-file `frozen.html` is the most robust input for every exporter and
   sidesteps path-rewriting bugs entirely.

The reader picks a tier by page kind; the user can force `monolith` for
stubborn pages.

## CSS asset rewriting

The naive tag walker does not see `url(...)` inside stylesheets. Parse fetched
CSS for `url()` and `@import`, download those too, and rewrite. This is where
`pywebcopy`/`monolith` earn their place — reuse them rather than reimplement a
CSS parser (anti-bloat).

## Path sanitation

- Hash or namespace long/duplicate filenames to avoid collisions and path
  traversal (gemi's "hashed filenames for long paths" note).
- Keep the asset tree under `asset_dir`; never write outside `out/<slug>/`.
- Preserve enough of the original path to keep relative `@font-face` and
  `srcset` resolution intact.

## Fonts matter for fidelity

Pagination depends on font metrics. If a web font fails to localize, the engine
substitutes and line-breaks shift, breaking the `SlidePlan` ([09](09.md)).
Treat a failed `@font-face` download as a loud warning, and prefer the
`monolith` tier for font-heavy designs.

## Content hash

After localization, compute `PageDoc.content_hash` over the normalized HTML plus
a manifest of asset bytes. This is the cache key ([21](21.md)) and the
determinism anchor ([02](02.md)).
